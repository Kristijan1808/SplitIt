Web je samostalan React/Vite projekt. Ulaz: src/main.tsx, stranice: src/pages, komponente: src/components, tema: src/styles/fineLine.css. Razvoj: npm run dev iz korijena. Produkcija: npm run build -w @splitit/web. Mobilna aplikacija i API ostaju zasebni. apps/web/client, apps/web/scripts/unified.mjs i apps/web/src/interface nisu potrebni.
